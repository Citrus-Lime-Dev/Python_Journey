In Python, variables are symbolic names that act as references or pointers to objects stored in the computer's memory. 
You can think of them as labeled boxes that hold data you want to manipulate and reuse throughout your program.

Examples: 
name = "Kalyan"
age = 31
experience = 7.5
is_Employed = False
is_Married = True

-> Assignment: Assignment of values to the variables is done by using '=' operator.
-> Dynamic Typing: Dynamic Typing concept is used meaning the types are assigned to variables during run time.
-> variable names: variable names cannot start with a number , can start with underscore or a letter ,
                    hyphens are not allowed, no spaces in the name, A-z, 0-9 are allowed, reserved keywords are not allowed
-> case sensitivity: case sensitivity is valid.
-> constants: constants should be named with all uppercase letters in it.
