Datatype: Datatype defines the category of value stored in a variable, which determines which operations can be safely performed on it.

-> int : Whole numbers with unlimited precision.
-> float : Fractional numbers with a decimal point.
-> bool : Evaluates to either logical truth or falsehood.
-> str : A sequence of Unicode characters (text).
-> None : A special singleton representing "no value".

These are some basic data types only as of now.

type(value) -> Used to check the type of value of the variable.
isinstance(value, type) -> The isinstance(value, type) function in Python is a built-in function used to check if an object (the value) belongs to a 
                           specific data type or class (the type). It returns a boolean value: True if the object matches, and False if it does not.
